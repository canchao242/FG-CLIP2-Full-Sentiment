# FG-CLIP2 Full-v5 论文代码

这是当前 Full-v5 论文对应的整理副本，不是旧版 No-cross 发布包。英文主说明见 [README](README.md)。

## 使用顺序

1. 先运行 `python tools/verify_results.py`，无需数据集、权重或 GPU，即可复核公开预测文件中的全部五种子结果。
2. 要重新训练，按照 [复现步骤](docs/REPRODUCIBILITY.md) 安装环境、从原作者处合法取得数据，再重建固定划分。
3. 特征缓存需显式构建；父模型、No-cross 继续训练、Full-v5 分阶段训练依次运行。预览命令默认不开始实验，必须明确加入 `--run`。

## 公开与不公开的内容

公开：关键代码、固定配置、样本标识与划分顺序、数值预测、效率记录、测试与说明。

不公开：原始微博/推文、数据集照片、第三方图片、模型权重、特征缓存、账号密钥。MIT 许可不替代原始数据集及 FG-CLIP2 的许可。

固定划分标识不是匿名化保证，文本 SHA-256 只用于核对精确内容。不同版本数据、缺失图片或文本预处理不同会被校验脚本拒绝，不能通过删行或更换划分来声称复现。
